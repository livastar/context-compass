# Philosophy

Context Compass is built from a simple working belief: good agent work starts with orientation.

Context is not only files. It is the way instructions are layered, how tests prove promises, how recent commits reveal motion, how TODOs expose unfinished thought, and how docs describe the project's truth boundary.

The plugin is designed for conscious builders: people who want momentum without losing contact with intention, proof, and the human reason the work exists.

## Product Principles

- Orient before acting.
- Proof before scale.
- Local context before remote intelligence.
- Small surface, high quality.
- Recommendations must cite evidence.
- A personal origin can produce a generic tool.
